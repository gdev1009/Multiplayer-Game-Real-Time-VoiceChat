Match Word — Security

How we protect your data · Grandma Mac

Grandma Mac takes reasonable measures to protect Match Word players and their data.

Encryption in transit

All communication between the App and our servers uses HTTPS/TLS. Voice chat sessions use encrypted real-time channels provided by our infrastructure partners.

Authentication

Sign-in uses industry-standard authentication (email magic links / OTP via Supabase Auth). Session tokens are stored securely on device using platform keychains where available.

Backend access

Database access is restricted with row-level security policies so players can only read and write data appropriate to their account and active games.

Payments

Subscription payments are processed entirely by Apple or Google. We do not store credit card numbers.

Reporting issues

If you discover a security vulnerability, please email security@grandmamac.com with steps to reproduce. We will investigate promptly.
