# Idle pose frames (Milestone 7)

Generated by editing the **current artist base bodies** (not inventing new ones):

```
python3 tools/generate_idle_poses.py
```

Source bodies (never overwritten by that tool):

- `../base/body-female.png`
- `../base/body-male.png`

Each PNG is 1254×1254, transparent, aligned to the same head-top / feet bbox as
its source body so it can stand in as a temporary base layer under hair /
outfit / glasses.

| Pose | Notes |
| --- | --- |
| `tongue`, `worry`, `smug` | Face-only — safe under layered accessories |
| `shrug`, `hairfix`, `selfie` | Arm gestures — better on base-only figures |
